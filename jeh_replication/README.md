# The Effects of Prohibiting Marriage Bars: The Case of U.S. Teachers

**Authors:** Amy Kim (kimamy@princeton.edu) and Carolyn Tsao (carolyntsao@microsoft.com)  
**Journal:** Journal of Economic History (forthcoming)  
**Last updated:** April 2026

---

## Overview

This folder contains replication code and data for the paper, which studies the effects of prohibiting marriage bars — policies that barred married women from employment — in U.S. public schools. The paper uses a difference-in-differences (DiD) design comparing counties in states that removed marriage bars in the mid-1930s to neighboring Southern control counties, using U.S. Census data from 1910 to 1950.

The analysis produces:
- **5 main tables** (LaTeX): summary statistics and OLS regression results
- **4 main figures** (PNG): distribution plots and DiD event-study graphs

## How to Run

> **Note on `link1-3` files:** The individual-level linked files (`link1_swt_indiv.csv`, `link2_mwnilf_indiv.csv`, `link3_swnilf_indiv.csv`) are not included in this package due to IPUMS data redistribution restrictions. You must generate them by following the instructions in [Obtaining and Preparing Raw Data](#obtaining-and-preparing-raw-data) below and running `code/clean_data.R` before proceeding. The county-level files (`countysumm*.csv`) are provided directly.

1. **Open `code/_main.R`** and fill in the **USER CONFIGURATION** block at the top:
   ```r
   root = "<YOUR PATH>/jeh_replication"   # path to this folder
   ```
   If the `link1-3` individual-level files are missing (see note above), also set:
   ```r
   rawdata          <- "<YOUR PATH>/ipums_raw"
   censustreepath   <- "<YOUR PATH>/censustree"
   retailsales_file <- "<YOUR PATH>/retailsales_data.xls"
   ipums_format     <- "multi"   # or "single" — see README Obtaining and Preparing Raw Data
   ```

2. **Set output toggles** (optional):
   ```r
   verbose = TRUE   # print figures/tables to console as code runs
   save    = TRUE   # save outputs to the output/ folder
   ```

3. **Run the script** from R or RStudio:
   ```r
   source("code/_main.R")
   ```
   This will automatically source `helper.R`, `tables.R`, and `figures.R` in order.

4. **Check outputs** in the `output/` folder: 7 `.tex` table files and 4 `.png` figure files.

### Script Execution Order

```
code/_main.R
  ├── loads packages and imports all 6 data files
  ├── filters to balanced panel samples
  ├── sources code/helper.R   → defines DiD regression and graphing functions
  ├── sources code/tables.R   → generates Tables 1–5
  └── sources code/figures.R  → generates Figures 1–3
```

## Data Dictionary

### Internal Variable Definitions
The data files available in this replication package are constructed by aggregating individual-level IPUMS data. Prior to aggregation, we construct the following individual-level variables from the raw IPUMS data:
- `man`: `SEX == 1`
- `singlewoman`: `SEX == 2 & MARST != 1 & MARST != 2`
- `marriedwoman`: `SEX == 2 & (MARST == 1 | MARST == 2)`
- `worker`: In the labor force and age 16-64 (`LABFORCE == 2 & AGE >= 16 & AGE <= 64`)
- `teacher`: Working as a teacher and not self-employed (`OCC1950 == 93 & CLASSWKR == 2 & worker == 1`)

### County-Level Data Files

`countysumm.csv`, `countysumm_blk.csv`, and `countysumm_wht.csv` are constructed by aggregating IPUMS individual-level records to the county × census-year level. We use two types of aggregations in this dataset: (1) general county aggregations, which are constructed from the entire county x year population, and (2) teacher aggregations, which are constructed only from the population of teachers in the county x year. The three different files share the same variable structure and *differ only in the population of teachers used for the teacher aggregations* and the `mainsamp*` sample indicator. 

- `countysumm.csv`: All teachers
- `countysumm_blk.csv`: Black teachers only (restricted to counties with Black teacher observations)
- `countysumm_wht.csv`: White teachers only (restricted to counties with white teacher observations)

Unit of observation: county × census year (1910, 1920, 1930, 1940, 1950)

**Identifiers & Sample Indicators**

- `YEAR`: Census year (1910, 1920, 1930, 1940, or 1950)
- `STATEICP`: State code (Raw IPUMS Variable)
- `COUNTYICP`: County code (Raw IPUMS Variable)
- `FIPS`: County FIPS code (constructed using STATEICP-FIPS crosswalk + first 3 digits of COUNTYICP)
- `SOUTH`: = 1 if county is in a Southern state
- `TREAT`: = 1 if county is in a state that removed marriage bars (1933–1940); = 0 for control counties
- `neighbor_samp`: = 1 if county is in the balanced neighbor panel (treatment + neighboring control counties present in all years)
- `mainsampall`: = 1 if county meets main sample criteria for the all-teachers analysis, i.e. at least 1 teacher in all years and at least 10 teachers in county in both 1930 and 1940 (`countysumm.csv` only)
- `mainsampblk`: = 1 if county meets main sample criteria for the Black-teachers analysis, i.e. at least 1 Black teacher in all years and at least 10 Black teachers in county in both 1930 and 1940 (`countysumm_blk.csv` only)
- `mainsampwht`: = 1 if county meets main sample criteria for the white-teachers analysis, i.e. at least 1 white teacher in all years and at least 10 white teachers in county in both 1930 and 1940 (`countysumm_wht.csv` only)

**General County Characteristics** 
These variables are constructed simply by aggregating individual-level variables/indicators across the entire population of the county x year. These variables are identical across all three files.

- `POP`: Total county population
- `SCHOOLPOP`: School-age population (children age 6–18)
- `URBAN`: Share of county population living in urban areas (`URBAN == 2`)
- `LFP_MW`: Labor force participation rate of married women (total married women workers [`marriedwoman == 1 & worker == 1`] over total working-age married women [`marriedwoman == 1 & AGE >= 16 & AGE <= 64`])
- `LFP_WMW`: Labor force participation rate of white married women (same as above, restricting both denominator and numerator to `RACE == 1`)
- `NCHILD`: Average number of children among married women (mean of NCHILD among married women)
- `UNEMP_RATE`: County unemployment rate (total unemployed workers (`worker == 1 & EMPSTAT == 2`) over total workers (`worker == 1`))

**Teacher Characteristics**
These variables are constructed by restricting the individual-level Census to those with `teacher == 1` (`countysumm.csv`), those with `teacher == 1 & RACE == 2` (`countysumm_blk.csv`), or those with `teacher == 1 & RACE == 1` (`countysumm_wht.csv`), and aggregating across this teacher population for a given county x year.

- `num_Teacher`: Total number of (total/Black/white) teachers in county
- `pct_mw_Teacher`: Share of (total/Black/white) teachers who are married women
- `pct_m_Teacher`: Share of (total/Black/white) teachers who are men
- `pct_sw_Teacher`: Share of (total/Black/white) teachers who are single (unmarried) women
- `pct_Teacher_mw_100`: Number of (total/Black/white) married women teachers per 100 (total/Black/white) married women in the county [note: this variable is computed at the county-level after merging to general county characteristics]

**Robustness / Appendix Variables**
These variables are not used in the primary analysis in this replication package, but are used in several of the appendix specifications and are therefore provided for additional analysis. See the Online Appendix for further details on the matched robustness checks, the Secretary placebo test, and the Border County specification.

- `match_weight1`: Matched sample indicator (nearest neighbor specification)
- `match_weight2`: Matched sample indicator (genetic matching specification)
- `match_weight3`: Inverse propensity score matching weight (full optimal)
- `pct_m_Secretary`: Share of (total/Black/white) secretaries who are men (comparison occupation placebo)
- `pct_mw_Secretary`: Share of (total/Black/white) secretaries who are married women (comparison occupation placebo / Figure 1)
- `pct_sw_Secretary`: Share of (total/Black/white) secretaries who are single women (comparison occupation placebo)
- `bordertreat`: = 1 if county borders a treated state (border robustness checks)
- `borderctrl`: = 1 if county borders a control state (border robustness checks)

### Individual-Level Linked Data Files

`link1_swt_indiv.csv`, `link2_mwnilf_indiv.csv`, and `link3_swnilf_indiv.csv` are *individual-level* datasets that link individual women across two consecutive census waves (a 10-year panel) using linking files from **CensusTree** ([censustreepublic.org](https://www.censustree.org/data)). We use linkages between 1910-1920, 1920-1930, and 1930-1940. Linkage of the full censuses is done following instructions on the CensusTree website. Variables from the base year (t-10) are labelled with suffix `_base`, while variables from the linked census (t) are labelled with suffix `_link`.

We then filter the full linked census sample to three different samples, each capturing a different baseline population at t-10:

- `link1_swt_indiv.csv`: Women who were teaching and unmarried in t-10 (Tables 3 Panel 1, 5)
- `link2_mwnilf_indiv.csv`: Women who were married and not in the labor force at t-10 (Table 3 Panel 2)
- `link3_swnilf_indiv.csv`: Women who were unmarried and not in the labor force at t-10 (Table 3 Panel 3)

These files share the same variable structure; they differ only in the baseline labor market state used to construct each sample.

Unit of observation: individual woman × census year. Base-Link Years: 1910-1920, 1920-1930 (reference), 1930-1940.

**Identifiers & Treatment**

- `STATEICP`: State code (IPUMS ICP coding)
- `COUNTYICP`: County code (IPUMS ICP coding)
- `FIPS`: County FIPS code
- `YEAR`: Census year of the outcome observation (t)
- `SOUTH`: = 1 if county is in a Southern state
- `TREAT`: = 1 if county is in a marriage-bar-removing state

**Individual Characteristics**

- `RACE`: Individual's race (IPUMS coding)
- `AGE`: Individual's age at time of outcome observation
- `neighbor_samp`: = 1 if individual's county is in the balanced neighbor panel

**Outcomes: Married Women's Labor Market States (Tables 3, 5)**

- `married_link`: = 1 if woman is married in t
- `mwt_link`: = 1 if woman is married and teaching in t
- `mwnt_link`: = 1 if woman is married, in the labor force, and not teaching in t
- `mwnilf_link`: = 1 if woman is married and not in the labor force in t

**Outcomes: Unmarried Women's Labor Market States (Table 5)**

- `unmarried_link`: = 1 if woman is unmarried in t
- `swt_link`: = 1 if woman is unmarried and teaching in t
- `swnt_link`: = 1 if woman is unmarried, in the labor force, and not teaching in t
- `swnilf_link`: = 1 if woman is unmarried and not in the labor force in t

**Appendix Variables**

- `nlink`: Number of linked individuals in the sample in a county x year
- `URBAN`: = 1 if individual resides in an urban area (used in heterogeneity analyses)
- `OCCSCORE_link`: Occupational income score in t (net effects appendix)
- `NCHILD_link`: Number of own children in household in t (net effects appendix)
- `worker_link`: = 1 if woman is in the labor force in t (net effects appendix)
- `move_state`: = 1 if woman moved to a different state between t−10 and t
- `match_weight1`: Matched sample indicator (nearest neighbor specification)
- `match_weight2`: Matched sample indicator (genetic matching specification)
- `match_weight3`: Inverse propensity score matching weight (full optimal)
